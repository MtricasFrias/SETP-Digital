# SETP Digital

Propuesta técnica de arquitectura empresarial para el SETP Ibagué (TransMusical), basada en el kit de productos tipo de MinTIC y la Política de Gobierno Digital.

**Documento de trabajo no oficial.** No es un sitio del SETP Ibagué S.A.S. ni de la Alcaldía de Ibagué. Autor: Jhonny Murillo, Arquitecto.

El sitio es un único archivo (`index.html`) sin dependencias externas. Comentarios y correcciones: pestaña *Issues* de este repositorio.
